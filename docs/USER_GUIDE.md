# Study Planner 使用指南

## 第一次打开

程序在本机运行。首次打开没有课程，也没有维护者的个人数据。你可以先添加一件待办，再去设置载入课表；不需要注册，也不需要 AI Key。

Windows 使用包：解压，双击 `StudyPlanner.exe`，保持启动窗口打开；浏览器未打开时访问 http://127.0.0.1:8765。关闭启动窗口停止服务，下次双击同一文件即可继续。

## 载入课表

在设置中下载课表转换 Skill，把它和自己的课表材料一起交给 AI，生成可下载 JSON。确认第一教学周的周一、学期周数、上课周次与节次；只有钟点时提供节次映射。拖入 JSON 后先检查预览，再点击载入。

课程按具体日期展开。重复键为「日期、课程名、开始节、结束节」，教师或地点不同也可能被视为重复；先在 AI 整理时确认差异。导入不会覆盖已存在的主题或复习链。第一次向空课表导入时设置学期元信息，已有课表的学期信息不会被自动替换。

默认时区是北京时间；当前支持 1–12 节、1–54 周。节次钟点表暂时固定，请先查看自己的学校是否匹配，不能把显示钟点当成所有学校的标准。

## 复习如何生成与顺延

1. 课程只是课表上的时间安排。填写“本节主题”后，该课程才生成复习链。
2. 默认间隔为 1、3、7、14、30 天，可在设置里调整；新生成的复习链使用新间隔。
3. 晚录入主题时，按当前可执行日期安排，避免刚录入就出现一批历史逾期任务。
4. 最早轮次逾期时，移动到今天，尚未完成的后续轮次随之顺延；完成与撤销可影响后续日期，请观察清单。
5. 清除主题会移除该课程尚未完成的复习链，已完成记录保留。

这是一套计划规则，实际复习效果还取决于学习内容与执行方式。

## 待办、到期与回收站

待办清单里打钩完成任务；在原行编辑图标里修改计划时间、截止时间、类型和备注。没有任何日期的未完成任务在“全部事项”的“未安排日期”中。

到期清单只提醒，不单独打钩。任务完成后它的截止提醒消失；过期未完成仍需要处理，并不是过了截止时间就自动完成。

只有日期的截止时间按当天 23:59 处理。距离截止不到 24 小时出现提醒，不到 12 小时有更明显的提醒卡。删除后可短时撤销，也可在回收站恢复；倒计时结束不会永久清空任务。

## 周课表与月清单

周课表只看课程，适合查看上课节次。月清单看复习、待办和 DDL；“全部”显示三类，绿／黄／红点分别对应复习、待办、DDL。一个月格里装不下时，可点击日期查看详情。

## 外观、AI 与快捷键

选择主题，调整密度和字号。前三套主题颜色锁定；“纯色”允许选一个主色，其余颜色自动衍生。字号拖动即时预览，点击保存外观后记住设置。

AI 是可选功能。在本机设置中填写 API 服务地址、模型与 Key，点击测试连接。保存后也会自动测试；单独测试不保存配置。模型可用性以实际测试为准。

一句话解析将输入发送给你配置的服务，把任务与备注填入表单；核对后点击添加才保存。密钥不要发到聊天或 GitHub。

设置底部有完整快捷键说明，按 `?` 可以直接定位。输入和编辑时暂停页面切换快捷键。

## 升级与备份

数据在程序旁边的 `data/`。移动软件时，应移动整个软件文件夹；只把 exe 移到别处会让它在那里新建另一份数据。

升级前关闭旧程序，备份整个旧文件夹。将新包中的程序文件放进旧目录，保留原 `data/`，再启动检查原记录。程序也会创建数据库备份，但整文件夹备份便于回退程序和配置。

不要同时运行两个实例操作同一个数据目录。若升级失败，关闭新程序，恢复此前备份的程序与数据；不要在新旧数据库之间反复混拷。

## 常见问题

| 问题 | 处理方式 |
| :--- | :--- |
| 下载的是源码，没有 exe | 下载 Release 中的 `StudyPlanner-Windows-x64.zip`，而不是 Code 菜单的源码 ZIP。 |
| 课表是空的 | 新安装就是空课表，先从设置载入自己的课表。 |
| 程序被系统提醒未签名 | 核对官方来源与 SHA256，不关闭系统保护；可选择审阅源码后运行。 |
| 端口被占用 | 先确认旧项目窗口，或让 AI 使用另一空闲端口；不要结束未知进程。 |
| 关闭程序后页面不能继续操作 | 页面依赖本机服务，重新双击程序，再刷新页面。 |
| API 无法连接 | 查看测试反馈，核对服务、模型和 Key；不影响手动功能。 |
| 换电脑后 Key 无法使用 | Windows 本地 Key 受系统保护，在新电脑设置中重新配置。 |

需要反馈时在仓库 Issues 描述复现步骤，遮住个人课表、备注和 Key，不上传数据库。
